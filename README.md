# AI Sentiment Analysis

An AI-powered sentiment analysis application built with Streamlit, LangChain, and Groq.

## Features

- Sentiment Analysis
- Topic Extraction
- Follow-up Question Generation

## Technologies

- Python
- Streamlit
- LangChain
- Groq API

## Run

pip install -r requirements.txt

streamlit run app.py
